# 本地轻量模型验收契约

本页保留 2026-11-10 确认的比较条件与验收目标。日常部署已使用 8K Chat 窗口，复测时按实际模型配置分组记录。

## 1. 固定比较条件

目标为本地单机开发演示，常态一个交互请求，首轮并发为两个 RAG 重叠。只比较已确认三模型：

| 用途 | 固定模型与执行 |
| --- | --- |
| Chat / support / Agent | ekip-qwen3:4b-instruct-4k，Ollama，4B Instruct Q4_K_M |
| Embedding | ekip-qwen3-embedding:0.6b-4k，Ollama，0.6B Q8_0，1024 维 |
| Rerank | ekip-qwen3-reranker-0.6b，llama.cpp，qwen3-reranker-0.6b-q8_0.gguf，Cohere 兼容 |

通过 Java 正常授权入口和模型管理登记执行，参考 fixed + hybrid-rerank + support，recallN=20、topK=5、compression=none、MMR/父块扩展关闭，生成不超过 300 汉字。记录实际源码/产物/策略、模型摘要/语义指纹、量化/上下文/Token 上限、解码/超时/重试、资源组和驱动；凭据只记录是否配置。不同引擎、提示、索引、长度和模型驻留状态分组，不拼接成绩。

使用独立账号/KB/会话及明确归属的临时依赖，不操作共享业务数据。运行器先核对 modelExecution、授权和当前用途；旧环境变量不能替代绑定。质量通过后才扩展负载，不默认恢复历史全量验收。

## 2. 质量门与护栏

| 分组 | 样本 | 原目标 |
| --- | --- | --- |
| RAG 正例 | 48 条，六类各 8 条 | 总计 ≥44/48，每类 ≥7/8 |
| RAG 拒绝反例 | 40 条，五类各 8 条 | 审查正确拒绝 40/40；完整入口为 no_evidence 且公开证据为空；误准入 0 |
| Agent | 检索、显式分页、自主续读、逐字引用各 5 条 | 总计 ≥18/20，每组 ≥4/5 |
| 必需证据 top5 完整命中 | 48 个正例，人工标注可替代证据组 | 每题所有必需组都命中才算完整，至少 46/48 |

事实、限制、知识要点和引用须正确，要求的工具动作须真实执行；分页核对游标/偏移和内容，代号及逐字引用逐字符比较。正例拒答、超时、依赖故障、无效结构或跳过必要工具均记失败。4B 自评只辅助，真值来自已确认标签，缺评分为 null。

越权来源、虚构引用/工具完成、故障伪装无证据，任一发生则该批护栏失败。反例即便生成最终拒答，审查误准入仍计门禁失败。首轮每题一次；未声明范围、别名、跨项目、自主续读中的 10 个高风险场景各另重复两次，逐次保留。

当前两套已用数据都参与过诊断/修复，只能称已知回归，不能继续充当独立留出。新泛化需新正文、数值与问法，运行前固定标签；不改失败标签或挑成功重跑来核销。召回不全查检索，候选全但不准入查审查，准入后拒答/错误查生成。

## 3. 延迟、并发与冷启动

客户端单调时钟从发请求前计至完整 JSON 或 SSE done/error。RAG 同步/SSE、Agent 同步/SSE分别测；每个所选入口预热后固定顺序 100 次。RAG 先覆盖原 88 场景，再均衡补为正反例各 50；Agent 20 题各五次。排序后取 ceil(p×n)，n=100 的 P95 为第 95 个，报告 P50/P95/最大值和逐条结果。

| 场景 | 原目标 | 批次和完成条件 |
| --- | --- | --- |
| 预热单 RAG | P50 ≤6 秒，P95 ≤12 秒 | 每所选入口 100 次；终态 100/100；正例成功 ≥45/50，反例零误准入 |
| 预热单回合 Agent | P50 ≤15 秒，P95 ≤45 秒 | 每所选入口 100 次；成功 ≥90/100，各类 ≥80%，终态 100/100 |
| 两个 RAG 重叠 | 每请求 P95 ≤20 秒 | 20 对共 40 次，每对一正一反；启动屏障证明重叠，结果/终态符合预期 40/40 |
| 首个冷请求 | RAG ≤30 秒，Agent ≤90 秒 | 各 5 次，逐次达标；有模型驻留/加载证据，重启 AI 但模型驻留不算冷态 |

耗时包含成功、拒绝、超时和依赖故障；无终态保留等待时长/删失标记，该批不通过，不能删掉失败路径美化分位数。记录零静默重试、零丢失终态、模型原生 OOM 为零。正文完整校验后交付，阶段事件单列；冷态、故障注入、超载各自报告。

生成问答默认服务总预算 270 秒，Java 纯检索和 Agent 知识工具最多 35 秒，Agent 回合预算 120 秒。客户端完成还含传输与清理开销。上表性能目标按场景独立计时。local-gpu 目标容量 1，RAG 在途槽默认 4，模型等待队列默认 8；请求接纳、模型等待和 GPU 同时推理分别记录。两个 RAG 的成绩不外推为两个 Agent 或两个 GPU 推理。共享模型驻留状态如需改变，先限定目标与影响范围。

## 4. 使用与证据边界

有定向测试不等于真实模型通过，有隔离通过不等于共享环境部署，有原质量批次通过不等于独立泛化或正式容量通过。每次只按所选功能登记版本、固定输入、预期、实际结果与清理状态，不累计不同批次测试数作为项目完成率。待办 V01–V08 的原编号继续用于定位，旧日志或本文中的说明都不自动授权执行命令。
