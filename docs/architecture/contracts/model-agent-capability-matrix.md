# 模型与 Agent 能力边界

配置前先核对厂商端点提供的实际能力。模型登记和索引操作见[模型管理手册](../../model-management.md)。

| 用途 | 支持的协议与需验证的能力 |
| --- | --- |
| Chat | OpenAI 兼容 Chat。按用途核对文本、结构化输出和流式终态。 |
| Agent | 使用同一 Chat 协议。执行工具的模型须支持原生工具调用。 |
| Embedding | OpenAI 兼容 Embedding。输出维度须匹配知识库活动向量空间。 |
| Rerank | Cohere 兼容及百炼原生。score 模式须为当前模型语义配置独立校准。 |

<a id="旧配置迁移"></a>
需要使用已有文档切换模型或维度时，由知识库创建者显式发起重建。失效的个人用途绑定可在设置中改为受支持的模型，也可清除覆盖以恢复部署默认。标准检查项见[轻量模型验收标准](lightweight-acceptance.md)。
