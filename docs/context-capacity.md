# 长资料问答与输入容量

问答与 Agent 会按所选模型的上下文窗口估算单次输入。页面显示的累计 Token 是另一项指标。长资料超出本次容量时，服务可以整理重复内容或摘录相关原文。问答仍按完整问题审核证据，包括日期、条件和例外。必需内容放不下时会提示容量不足，资料确实缺证时会拒答。

从[长资料演示入口](../scripts/context-capacity-demo/README.md)复现。提问时可留意是否触发整理，随后检查答案里的时间、条件和引用原文。日常启动方式见[快速开始](../README.md#quickstart)。
